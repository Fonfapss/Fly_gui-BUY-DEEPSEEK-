# LAN Broadcast NeoForge Mod (1.21.1)

Этот мод для **NeoForge dedicated server** отправляет LAN-объявления (multicast `224.0.2.60:4445`) в формате vanilla LAN ping.
Из-за этого сервер появляется в списке **"Локальная сеть (LAN)"** у клиентов Minecraft в той же сети.

## Что делает мод
- При старте dedicated-сервера запускает фоновый поток.
- Каждые ~1.5 сек отправляет пакет:
  - `[MOTD]<motd>[/MOTD][AD]<port>[/AD]`
- При остановке сервера останавливает поток.

## Сборка
```bash
./gradlew build
```

Готовый jar будет в `build/libs/`.

## Установка
1. Установи NeoForge `1.21.1` на сервер.
2. Скопируй jar мода в папку `mods/` на сервере.
3. Запусти сервер.

Клиентам мод не нужен: используется стандартный механизм LAN-обнаружения.
